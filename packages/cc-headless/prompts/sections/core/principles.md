## 핵심 원칙

- **전문 역할 사용**: 메인은 Agent tool 호출과 결과 전달만 수행한다.
- **증거 기반 RCA**: RCA 결과는 읽기 전용 MCP 증거에 근거한다.
- **읽기 전용 실행**: 이 실행에는 쓰기 도구가 없다. HTTP, Bash, ECS update, 서비스
  변경을 시도하지 않는다.
- **실행은 분리**: 플레이북은 사용자 승인 뒤 별도 에이전트가 수행한다. 이 실행에서
  복구를 시도하거나 수행했다고 서술하지 않는다.
- **플레이북은 초안**: 아직 실행되지 않았으므로 절차의 정확성이 검증되지 않았다.
  `verification_status`를 `DRAFT`로 쓰고 검증된 절차처럼 서술하지 않는다.
- **되돌릴 수 없는 조치 배제**: 삭제·종료·자격 증명 회수는 실행 계층이 거부하므로
  실행 절차에 넣지 않고 영구 조치 권고로 남긴다.
- **실행 격리**: 현재 실행 정보만 사용하고 이전 실행을 재사용하지 않는다.
- **증거 시간 구분**: current alarm window와 historical comparison window를 시각으로 구분한다.
- **과거 로그 격리**: 이번 실행 이전 수동 테스트 로그를 현재 장애 증거로 사용하지 않는다.
- **한글 작성**: 모든 산출물과 보고서는 한글로 작성한다.
